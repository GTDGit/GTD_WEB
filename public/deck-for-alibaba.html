Slide 03 | Market Problem

Three practical gaps GTD is addressing in the Indonesian market.

The opportunity is not abstract. These are workflow-level problems that repeatedly appear in regulated onboarding and distributor-style transaction channels.

KYC

Onboarding trust is harder to maintain

Photo-only checks are increasingly insufficient. Buyers want stronger liveness controls, document validation, and audit-friendly verification artifacts.
API

eKYC workflows are still fragmented

Many teams still combine manual review, point vendors, and custom logic. That makes implementation slower, harder to maintain, and harder to explain during procurement.
NLP

Reseller commerce remains chat-first

Transaction activity already happens inside messaging apps, but safe automation needs better natural-language understanding, confirmation logic, and tool execution discipline.

Why this matters for Vison

Regulated onboarding teams need one clearer path for capture, verification, review, and storage rather than stitching together multiple moving pieces.

Why this matters for Sona

Reseller workflows need language-aware automation that can help complete real tasks without losing confirmation discipline or operational visibility.

Why this matters for Alibaba Cloud

Both product tracks translate into real workloads: training, inference, orchestration, regional deployment, and controlled data handling.

Slide 04 | Product 01

Vison is GTD's identity verification workflow for regulated onboarding.

Vison overview

Vison is being designed as a practical eKYC layer for Indonesian businesses that need to capture, validate, compare, and store onboarding evidence in a structured way.

Developer-friendly delivery through APIs, SDK surfaces, and a hosted verification flow.
Designed around real onboarding steps rather than standalone point-model demos.
Useful for fintech onboarding, reseller verification, and other identity-sensitive customer journeys.
Vison is the primary infrastructure workload in this application because it requires the most immediate investment in repeatable GPU training, benchmark discipline, and pilot-ready inference deployment.

Capture and liveness

Selfie capture, passive liveness logic, and challenge-ready flows that help move beyond static photo checks.

Document understanding

ID OCR, field extraction, and document-level validation logic aimed at reducing low-quality manual checks.

Face comparison

Selfie-to-document comparison and identity matching steps intended for structured verification outcomes.

Audit-ready outputs

Verdicts, artifacts, and logging paths that make verification easier to review internally and explain externally.

Deployment model

Vison is being shaped as a flexible delivery model: direct API integration for product teams, a JS embed surface for faster implementation, and a hosted flow for lighter deployment paths.
